# KAM015: a concurrency limit written as requests minus completions freezes after one refusal

A concurrency limit written as requests minus completions counts a refused request as a call
in flight for ever, on an engine that keeps the requests it refuses: a refused request is never
completed, so after one refusal the action is refused while nothing runs. The Credit ledger's
credit is the limit and its used the calls admitted or running; Tight fails at R0 after the
first refusal. This is the fix document's own caution: count what runs, not what was asked.

Level: **error** (`kamanu lint` exits 1). It needs lint's product machine (kamanu.fast.credit), so it is reported for a policy inside step 3's machine.

## Example

On an engine whose refusals leave a request in the history:

```dogwood
@id("one_call_at_a_time")
permit (principal, action == Drupe::Action::"Call", resource)
when temporal {
    (count for (t: Timepoint). where (
        formerly within 24h (Drupe::Action::"Call"::request{ input.user: context.input.user } && tp(t))
    ))
    - (count for (t: Timepoint). where (
        formerly within 24h (Drupe::Action::"Call"::response{ input.user: context.input.user } && tp(t))
    )) <= 1
};
```

lint's finding (line 5, column 51): KAM015 a concurrency limit written as requests minus completions freezes: on an engine whose refusals leave a request in the history a refused Call request stays in the history and is never completed, so it counts as a call in flight for ever; after one refusal Call is refused while nothing runs (Tight FAILS at R0).

The trace:

1. a caller a rule admits asks Call | ledger: credited 1, used 0, doubt 0
2. a caller a rule admits asks Call | ledger: credited 1, used 0, doubt 0
3. the engine decides Call: permitted | ledger: credited 1, used 1, doubt 0
4. the engine decides Call: refused | ledger: credited 1, used 1, doubt 0
5. a caller a rule admits asks Call | ledger: credited 1, used 1, doubt 0
6. Call completes and its effect lands | ledger: credited 1, used 0, doubt 0
7. the engine decides Call: refused | ledger: credited 1, used 0, doubt 0

Note: count what runs, not what was asked: admitted calls are what a refusal does not leave.
