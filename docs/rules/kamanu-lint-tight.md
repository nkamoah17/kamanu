# kamanu/lint/tight: No refusal of a request that fits beside held + spent + doubt (fast path)

Tight: no refusal of a request whose amount fits beside what is held, spent and in doubt,
judged at R1 and R2 (failures allowed). A FAILS carries the shortest trace to such a
refusal, told as a story. Level: error (`kamanu lint` exits 1).

## Example

```dogwood
permit (principal, action == Kamanu::Action::"Pay", resource)
when temporal { sum_within(a, 24h, Kamanu::Action::"Pay"::request{ input.amount: a }) <= 100 };
```

On an engine that decides before it records (Atomic false), R1 Tight FAILS; the story lint tells (`kamanu lint POLICY --engine ENGINE`):

```
story (R1 Tight, the ledger, 7 steps, cap 100):
   1. [harness] the harness issues a call for 60 | counted 0 | held 0 | spent 0 | doubt 0
   2. [harness] the harness issues a call for 60 | counted 0 | held 0 | spent 0 | doubt 0
   3. [engine] the engine admits the call for 60 | counted 0 | held 60 | spent 0 | doubt 0
   4. [engine] the engine writes the call for 60 into its history | counted 60 | held 60 | spent 0 | doubt 0
   5. [tool] the tool fails on the call for 60 and no money moves | counted 60 | held 0 | spent 0 | doubt 60
   6. [harness] the harness reconciles the call for 60: nothing moved, so it is given back | counted 60 | held 0 | spent 0 | doubt 0
   7. [engine] the engine refuses the call for 60 | counted 60 | held 0 | spent 0 | doubt 0   <- the invariant broke
```
