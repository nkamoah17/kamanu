# KAM016: an alert on exactly N counts attempts: a spurious alert (Sound) and a missed one (Tight)

An alert permitted on exactly N of another action's requests counts attempts on an engine
that keeps the requests it refuses: N refused transfers, none of which ran, raise the alert (a
spurious alert: Sound), and N transfers that ran beside one more that was refused do not (a
missed alert: Tight). lint prints both, each with its trace, at the counted pattern's line.
Read `Transfer::response` to count what ran.

Level: **error** (`kamanu lint` exits 1). It needs lint's product machine (kamanu.fast.credit), so it is reported for a policy inside step 3's machine.

## Example

On an engine whose refusals leave a request in the history:

```dogwood
@id("alert_on_three_transfers")
permit (principal, action == Drupe::Action::"Alert", resource)
when temporal {
    (count for (t: Timepoint). where (
        formerly within 1h (Drupe::Action::"Transfer"::request{ } && tp(t))
    )) == 3
};
```

lint's finding (line 5, column 54): KAM016 Sound: a spurious alert: the alert on exactly 3 counts attempts; on an engine whose refusals leave a request in the history a refused Transfer request stays in the history, so 3 refused Transfer requests (none ran) permit Alert.

The trace:

1. Transfer asked: refused
2. Transfer asked: refused
3. Transfer asked: refused
4. Alert asked: permitted

Note: an alert on attempts means attempts; read Transfer::response to count what ran.

lint's finding (line 5, column 54): KAM016 Tight: a missed alert: exactly 3 Transfer ran, one more was asked and refused, and Alert is refused, because the refused request is counted beside the ones that ran.

The trace:

1. Transfer asked: permitted
2. Transfer asked: permitted
3. Transfer asked: permitted
4. Transfer asked: refused
5. Alert asked: refused

Note: the missed alert's trace shows what ran, which the policy set may not admit; read Transfer::response to count what ran.

## Suppressing it

`// kamanu-ignore KAM016: <reason>` at the end of the pattern's line or alone on the line above it;
the reason is required, and the finding stays in the output and the SARIF.
