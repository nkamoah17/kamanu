# kamanu/lint/sound: Spent stays within the cap (fast path)

Sound: no reachable state where the money spent is above the cap, for any number of
requests within the bounds (calls in flight, failures). A FAILS carries the shortest trace
lint's machine finds (kernel steps, with what the count, held, spent and doubt are after
each), told as a story; every holds a witness and a failing neighbour one profile
coordinate away. Level: error (`kamanu lint` exits 1).

## Example

```dogwood
permit (principal, action == Kamanu::Action::"Pay", resource)
when temporal { sum_within(a, 24h, Kamanu::Action::"Pay"::request{ input.amount: a }) <= 100 };
```

On an engine that decides before it records (Atomic false), R0 Sound FAILS; the story lint tells (`kamanu lint POLICY --engine ENGINE`):

```
story (R0 Sound, the ledger, 8 steps, cap 100):
   1. [harness] the harness issues a call for 60 | counted 0 | held 0 | spent 0 | doubt 0
   2. [harness] the harness issues a call for 60 | counted 0 | held 0 | spent 0 | doubt 0
   3. [engine] the engine admits the call for 60 | counted 0 | held 60 | spent 0 | doubt 0
   4. [engine] the engine admits the call for 60 | counted 0 | held 120 | spent 0 | doubt 0
   5. [engine] the engine writes the call for 60 into its history | counted 60 | held 120 | spent 0 | doubt 0
   6. [engine] the engine writes the call for 60 into its history | counted 120 | held 120 | spent 0 | doubt 0
   7. [tool] the tool runs the call for 60 and the money moves | counted 120 | held 60 | spent 60 | doubt 0
   8. [tool] the tool runs the call for 60 and the money moves | counted 120 | held 0 | spent 120 | doubt 0   <- the invariant broke
```
